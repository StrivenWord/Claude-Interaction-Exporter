The production of the Claude Interaction Exporter browser extension was a primarily agentic process. The extension's transparent git history shows that it was built using Claude Code by three contributors (at the time of this writing). The selection of the Jekyll build system for this website, as well as the excellent theme, [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) by Michael Rose, was selected by human review.

The content here was largely directed using Claude Cowork but has been completely read and lightly edited by the publisher.

This present page and the [Contact]({{ '/contact/' | relative_url  }}) page are exceptions to the AI production workflow. These two pages were written entirely by the publisher.

At time of this writing, the entire codebase of the extension had been reviewed by the publisher and third contributor. Every line of code has been examined.
