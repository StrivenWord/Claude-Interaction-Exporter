Notable changes to the extension, newest first.

## Beta 1.0

The first public beta.

- Export the current conversation or Cowork session from the toolbar popup, in Markdown, plain text, or JSON.
- Browse page for searching, filtering, sorting, and bulk-exporting conversations and Cowork sessions as a ZIP.
- Structured YAML frontmatter on Markdown exports, including model name, project, contributor, tags, and a summary.
- Model inference for conversations where Claude.ai's API doesn't report one directly.
- Branch-aware exports: Markdown and plain text follow the selected branch; JSON keeps every branch.
