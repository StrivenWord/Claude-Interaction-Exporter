    An overview of what the extension can do today. Full walkthroughs live on the Usage page.

    Export the conversation you’re viewing

    One click from the toolbar popup exports the conversation or Cowork session currently open in the tab.

    Browse, search, and bulk export

    A dedicated browse page lists every conversation and Cowork session in sortable, filterable tables, with checkboxes for exporting a selection — or everything matching the current filters — as a single ZIP.

    Three output formats

    • Markdown — human-readable, with YAML frontmatter
    • Plain text — simple Human: / Assistant: transcript
    • JSON — the complete raw data, including every branch

    Structured frontmatter

    Markdown exports open with a YAML header carrying title, dates, model, project, tags, and a summary — ready to drop into Obsidian or any other note system.

    Model-aware

    Claude.ai’s own export does not record which model a conversation used. This extension does, and infers the model from the conversation’s date when the API doesn’t report one directly.

    Cowork sessions and scheduled tasks

    Cowork sessions and scheduled task runs export too, with their tool activity replayed into a readable transcript.
